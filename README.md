# Practice Director

One app for exam practice: it plans what to practise today, lets you do it (recall, questions, mocks, written answers), and brings back what you got wrong at the right time.

It combines the engines of Practice Desk and Revision Director with the Director Calendar library. It is built first for UPSC IFoS and CAT, and stays generic through exam templates and syllabus packs.
