# Design mock-up

`mockup/` holds the source of the design canvas: one `.dc.html` file per screen and `canvas.json`, which lays them out. The canvas is published as a private Claude artifact at https://claude.ai/artifact/XNuSS5dFNpLcTR2aXFeh31 (only its owner can open it). These files are the durable copy.

All names, scores and counts in the screens are sample data.

| File | Screen |
|---|---|
| `Main.dc.html` | Practice Director: Today, on a laptop |
| `Phone-flow.dc.html` | A daily session on a phone: recall, tap what you missed, a mistake re-attempted blind |
| `Written-answer.dc.html` | A written answer with the phone beside the paper |
| `Answer-sheet.dc.html` | Answer-sheet mode beside a PDF |
| `Results.dc.html` | Results as a story |
| `Syllabus.dc.html` | Syllabus with draining memory bars |
| `Progress.dc.html` | Progress: the road, two priorities, papers against target, load |
| `SD-Plan-concept.dc.html` | Concept for Study Director: Plan with a margin |

The mock-up was reviewed and reworked once (14 Nov 2026). What it does not yet show is listed in `docs/PLAN.md`, section 12.
